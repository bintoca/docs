# Access points

An access point is your account on bintoca. It owns your workspaces, permission groups, shared access settings, and sessions.

## Name and URL

Access point names:

- are 5 to 20 characters long;
- use lowercase letters and digits only; and
- cannot contain spaces, hyphens, or other punctuation.

Your access point URL is:

```
https://bintoca.com/access/<access-point>
```

The name also appears in every workspace hostname:

```
https://<workspace>-<access-point>.bintoca.io
```

Choose the name carefully. It is part of the address you share with other people.

## Create an access point

1. Open [bintoca.com/signup](https://bintoca.com/signup).
2. Enter the access point name and your email address.
3. Select **Send verification code**.
4. Enter the 6-digit code from the email.
5. Select **Verify email**.

If the name or email is already in use, signup reports the problem instead of creating the access point.

## Sign in

1. Open your access point URL.
2. Select **Email me a sign-in code**.
3. Enter the 6-digit code sent to the registered email address.

The code is single-use and expires. Use **Resend code** if it does not arrive.

If you do not know your access point URL, open [bintoca.com/login](https://bintoca.com/login), enter your email address, and select **Email me my access link**. The email lists the access points registered with that address.

There is no password to manage. Anyone with access to the registered email address can sign in, so protect that mailbox.

## Navigate the access point

After signing in, the sidebar contains:

- **Home** — create your first workspace or start a session.
- **Workspaces** — create and delete workspaces.
- **Permissions** — create permission groups and rules.
- **Shared Access** — share your workspaces with another access point.
- **Sessions** — create and revoke browser sessions and bearer tokens.
- **My Account** — view the profile details for the signed-in user.
- **Feedback** — send a message to the bintoca team.

Use **Sign out** at the bottom of the sidebar when you are finished, especially on a shared computer.

## My Account

The account page shows the signed-in user's details:

- name, username, and email address;
- the access point name;
- whether the account is active; and
- when the account was created.

Multi-factor authentication and passkeys are not available yet. If you need to change the email address associated with an access point, contact support.

## Feedback

Use **Feedback** in the sidebar to report confusing documentation, request a feature, or describe a problem. Do not include passwords, bearer tokens, or other secrets in feedback.

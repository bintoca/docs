# Product documentation

bintoca gives you a private place to build and share web applications and files. You create an **access point**, add **workspaces**, control access with **permission groups**, and open workspaces with short-lived **sessions**.

These guides describe the current beta. Features and limits may change.

## Conventions

- A workspace URL looks like `https://<workspace>-<access-point>.bintoca.io`.
- Examples use `myapp` as the workspace name and `yourname` as the access point name.
- Commands assume you already have a session cookie or bearer token with permission for the workspace.

## Feedback
